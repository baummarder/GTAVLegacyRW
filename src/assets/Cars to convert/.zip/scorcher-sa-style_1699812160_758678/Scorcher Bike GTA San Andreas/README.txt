|------Bicycle Scorcher GTA SA------|

- If you want to install it normally (replacing), open the "modloader" folder, choose a folder with the bike
  you like and drop it into your GTA modloader. If you have CLEO, move the "scorcher_name" file to cleo_text.

- If you want to install it without replacing anything, go to the "add. without replacing" folder, which contains
  both models of the mod, the handling entries and an "[ID]" placeholder where you pick a number, plus the .fxt
  file that shows the bike name in game. I recommend adding it for a better experience.

- You do not need to change anything in "cargrp.dat"; the names are already there so the bike spawns with NPCs.

- Please leave credit to the author if you repost the mod or upload it elsewhere!
